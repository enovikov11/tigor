Containerized autonomous improvement agent loop — runs opencode in a sandbox, making commits across multiple parallel branches (slots).

## What it does

Sets up a Docker Compose environment with a local LLM (llama.cpp/vLLM serving SIQ-1-35B or similar models) and an opencode agent that runs in an infinite loop. The agent:

1. Maintains exactly 10 parallel "slots" (branches), each tracking an independent improvement task
2. Each iteration: picks a slot, explores the codebase, makes one focused change (<30 lines diff), validates, commits, updates state
3. Operates with NO internet access — fully air-gapped sandbox
4. Uses a shared state file (`loop-state.md`) for durable memory across iterations
5. Reads a detailed "meta.md" guardrails document defining quality rules, exclusions, and slot management

The loop driver (`loop.sh`) manages worktree cleanup, config injection, and iteration logging. The benchmark tracks which slots produce useful changes and which are blocked/rejected.
