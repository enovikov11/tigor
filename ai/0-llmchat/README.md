# LLM Chat Bot (0-llmchat)
> **Note:** This README was auto-generated by AI as a project summary. For detailed technical notes, see `README-tech.md`.

Prototype Telegram chatbot that reads exported chat history and generates in-character replies using local LLM inference.

## What it does

Loads a Telegram chat export (JSON format), builds a prompt from a sliding window of recent messages, and sends it to a local vLLM endpoint (Qwen3.6-27B-FP8) to generate a reply in the persona of a "sane, highly skilled demon" character (honkbot/xecutbot). The bot:

- Uses a 100-message sliding window with configurable skip offset
- Normalizes Telegram's complex message format (text can be lists of entity objects, photos have no text, etc.)
- Outputs a JSON reply with `thinking`, `id`, `author_name`, `text`, `reply_to_id`, `confidence_score`
- Includes confidence calibration in the system prompt (0.9+ simple, 0.5-0.8 opinions, <0.5 uncertain)

Currently prototype stage: `build_prompt.py` constructs prompts and sends to LLM for testing. No live Telegram bot integration yet.
