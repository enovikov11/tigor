# Telegram Coding Agent (p-agent)
> **Note:** This README was auto-generated by AI as a project summary. For detailed technical notes, see `README-tech.md`.

Telegram-facing bot that dispatches coding tasks to autonomous agents, runs them in disposable sandboxes, and pushes review branches.

## What it does

A production Telegram bot that receives coding commands (`/cd`, `/qwen`, `/minimax`), clones the monorepo into a fresh `/work/<timestamp>` directory, runs the selected AI coding agent (Claude Code, opencode with Qwen or MiniMax), commits the result, pushes a branch to Forgejo, and returns compare/cherry-pick links.

Security features:
- Admin-only access (`require_auth` decorator, Telegram user ID check)
- Emergency halt (`/halt`) — in-memory flag + persistent file, one-way (restart to resume)
- Configurable timeout (`/settimeout`)
- Environment variable masking in output (bot token, API key, git pass)
- Security tests built into Docker image (build fails if tests fail)
- Fresh disposable workspace per run
- Air-gapped execution (no internet inside the agent)

Supports OpenClaw gateway mode for personal AI assistant with multiple model providers (p-vllm for GPU, p-llama for CPU).
