## What it does

Manages the production LLM inference service on a dedicated server (RTX PRO 6000 Blackwell, 96GB VRAM, 64-core CPU). Currently serves Qwen3.6-27B-FP8 via vLLM nightly with:
- 262k context window
- FP8 KV cache
- Speculative decoding (MTP with 2 draft tokens)
- Tool calling and reasoning parsing
- Open WebUI frontend

Contains a comprehensive knowledge base (`inference.md`) documenting hard-won lessons:
- VRAM budgeting: model weights + runtime overhead + KV cache compete for the same pool
- MTP vs CUDA graphs trade-offs
- gpu-memory-utilization caps total VRAM (not just KV cache)
- max-model-len is per-request, not a memory lever
- Batch shape determines engine choice (vLLM for concurrency, llama.cpp for batch=1)
- Blackwell-specific: fp8 KV cache, FlashAttention, CUDA graphs all work

Also experiments with: Qwen3.5-122B-A10B (AWQ), Wan2.2 video generation, llama.cpp on RTX 3090, DeepSeek-R1-671B on massive CPU rigs.
