Telegram bot for text-to-video and image-to-video generation using the open-source Wan2.2 model (A14B).

## What it does

A full-featured Telegram bot that generates videos from text prompts or images using Wan2.2 (Alibaba's open video model). Features:

- **Text-to-video** (`/gen prompt`) — generates from scratch
- **Image-to-video** (attach/reply to JPG) — animates from a starting image
- **Parameter control** via command suffix: `/gen832w480h40s prompt` (width, height, frames, steps)
- **Chat access control** via `TELEGRAM_ALLOWED_CHAT_IDS`
- **Single-server concurrency control** via asyncio lock
- **CUDA memory management** — auto offload when switching models, manual cache clearing
- **Progress indication** — sends `UPLOAD_VIDEO` chat actions during generation
- **Auto-cleanup** — temp files cleaned up after each generation

Supported resolutions: 720x1280, 1280x720, 480x832, 832x480, etc.
Frame counts: 49, 81, 113, 145, 177 (must be 4n+1)
Steps: 20, 40, 60

The Wan2.2 model (~54GB bf16) fits on the RTX PRO 6000 single GPU. Also includes Containerfiles for ComfyUI integration.
