## What it does

Jupyter notebook that calculates whether building a home GPU/CPU server for LLM inference pays off compared to paying for commercial APIs (GPT-4, Claude, Gemini, Grok, etc.).

Analysis covers:
- Commercial API cost estimation at 7.5 tokens/sec sustained usage (~$157/month)
- Serbia electricity cost calculation (blue tariff, peak/low rates)
- Home build BOM: EPYC CPU (~€775), motherboard (~€740), RAM (~€1155), SSDs, cooling, PSU (~€3,682 total)
- Break-even analysis: total hardware cost / (monthly API savings - electricity) / 12 months
- Actual inference benchmark data from `roi.log.json` (Qwen3-235B on 64-core EPYC with 512GB RAM)

The data shows Qwen3-235B-A22B running on pure CPU (no GPU) at ~7-8 tok/s, which is surprisingly usable for chat on a massive MoE model that fits entirely in system memory via mmap.
