# ChatGPT Keyboard Hotkeys (2-gpt-hotkeys)
> **Note:** This README was auto-generated by AI as a project summary. For detailed technical notes, see `README-tech.md`.

Chrome extension that adds keyboard shortcuts to ChatGPT's interface for faster navigation.

## What it does

A Manifest V3 Chrome extension that injects keyboard shortcuts into chat.openai.com. Maps single keys to UI elements:

- **3** — Select GPT-3.5 model
- **4** — Select GPT-4 model
- **N** — Navigate to new chat
- **E** — Toggle edit mode
- **C** — Create (primary button) / Confirm
- **B** — Back/Cancel (neutral button)
- **M** — Model menu
- **T** — Temperature/advanced settings
- **P** — My plan
- **I** — Custom instructions
- **S** — Settings & Beta
- **H** — Toggle chat history (localStorage + reload)

Uses a MutationObserver to track DOM changes and annotate visible elements with `[KEY]` hints. Content script loads the main injection script dynamically via `chrome.runtime.getURL()`.

Note: This targets the **GPT-3.5 era** ChatGPT UI and is now obsolete (marked as "dead" in project metadata).
