## What it does

Predecessor to `2-llm-hardware` — an early attempt to benchmark local LLM inference on different hardware configurations. Tests 10 models (Llama 2, DeepSeek-R1, Qwen2.5, Phi-4, Command-R, Dolphin-Mixtral, etc.) across multiple runners:

- Apple M3 Max (128GB RAM, local)
- Various rented GPU instances via Vast.ai: RTX 4090, RTX 5090, RTX A6000, RTX 6000Ada, dual configurations, A100 SXM4
- OpenAI API (ChatGPT 4o, o1-mini, o1)

Uses Ollama for local inference and the OpenAI API for cloud. Measures characters-per-second throughput and produces a median comparison table. Prompts are from a curated JSON log (39 test prompts).
