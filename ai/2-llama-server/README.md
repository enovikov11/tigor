# Llama.cpp Inference Server (2-llama-server)

Over-engineered but comprehensive llama.cpp HTTP server with async task queue, auth, rate limiting, and multi-model support.

## What it does

A FastAPI-based inference server wrapping llama.cpp that supports:

- **Multiple huge models**: Qwen3-235B (Q4/Q8), DeepSeek-R1 (671B Q5/Q8, 70B Q8, 32B Q8) — all mappable from 512GB RAM
- **Async task queue**: Requests are queued (not blocking). Clients poll with the same payload until a result arrives (idempotent API)
- **Auth**: HMAC-signed bearer tokens with user-level permissions (priority, daily message limit, max tokens)
- **Daily rate limiting**: Per-user max messages per day
- **Memory-resident task store**: SQLite in-memory DB with TTL-based expiry (1 day)
- **Performance logging**: Every event (server start, model load, inference start/complete/error) logged with RAM stats to `events.json.log`
- **Model aliases**: Each model has multiple names (e.g., `deepseek` → `deepseek-r1-671b-q5-ctx4096-mmap-64T`)
- **Priority scheduling**: Tasks selected from queue with weighted random selection based on user priority

Runs on a 64-core EPYC with 512GB RAM — all inference is CPU-based (n_gpu_layers=0). Docker container served over Unix socket, mounted into the main Podman compose.

## Key Files

- `src/server.py` — FastAPI app: auth middleware, chat completions endpoint, inference thread, model loading
