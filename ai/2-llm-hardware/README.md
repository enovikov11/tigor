# LLM Hardware Benchmark (2-llm-hardware)
> **Note:** This README was auto-generated by AI as a project summary. For detailed technical notes, see `README-tech.md`.

Comprehensive benchmark suite comparing LLM inference performance across 15+ hardware configurations and 10 models.

## What it does

The primary LLM hardware benchmark project. Tests median characters-per-second across a matrix of:

**Models** (5 tested on each rig): Phi-4 14B, DeepSeek-R1 32B, Qwen2.5 32B, DeepSeek-R1 70B, Llama 3.3 70B
**Hardware** (15+ rigs): RTX 4090 (24GB), RTX 5090 (32GB), dual RTX 4090/5090, Mac M3 Max (128GB), RTX A6000 (48GB), RTX 6000Ada (48GB), A100 SXM4 (40GB), dual RTX 3090, and more
**Baseline**: OpenAI API (ChatGPT 4o, o1-mini) for comparison

Key insights from the benchmark:
- **GPU-first vs CPU-first strategies**: GPU rigs run 32B-70B models at chat speed; CPU rigs run 671B+ models 10x slower
- **Dual GPU scaling**: dual RTX 5090 (~$8100) reaches 129-136 tok/s on 70B models
- **Apple M-series**: power efficient but ~5x slower than equivalent GPU
- Only models with 95%+ "good answer" rate are included (quality filter)

Also serves as a **public GitHub project** with contribution instructions: anyone can run the benchmark on their hardware and submit results as a PR.
