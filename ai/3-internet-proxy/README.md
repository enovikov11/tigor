## What it does

Read-only internet proxy (data diode) for AI agents. The agent can only read content — never act on the internet. Each adapter strips non-content (no raw HTML, no executables). Supports web search, articles, YouTube, Wikipedia, Reddit, GitHub, Telegram, and package mirrors.
