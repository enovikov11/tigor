## What it does
A Telegram bot that performs semantic (similarity-based) search over chat message archives using OpenAI embeddings (`text-embedding-ada-002`) and FAISS for vector indexing. Supports both direct messages and inline queries. Built as a proof-of-concept for semantic search over conversational data.
