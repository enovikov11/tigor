Jupyter notebook analysis of the Belgrade real estate market — calculating price-to-rent ratios for apartments and visualizing them on an interactive map.

## What it does
- Scrapes rental and sale listing data from CityExpert.rs API for Belgrade (city ID 1)
- Trains a linear regression model to predict rent prices from location (lat/lng) and apartment size
- For each sale listing, computes the price-to-rent ratio: `sale_price / (12 * predicted_monthly_rent)`
- Visualizes results on an interactive Folium map with color-coded CircleMarkers (YlOrRd colormap, ratio 0-30)
- Uses an R-tree spatial index to find nearby rental listings for more accurate per-location rent estimation
- Also queries the Serbian Land Registry (katastar.rgz.gov.rs) API for official price data
- Separate notebook (`photo-old.ipynb`) uses GPT-4 Vision to evaluate apartment listing photos (detecting photoshopped/fake images)
