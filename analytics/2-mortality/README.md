# Mortality Probability Tables
> **Note:** This README was auto-generated by AI as a project summary. For detailed technical notes, see `README-tech.md`.

Generates visual mortality probability charts from US Social Security Administration (SSA) life table data, showing the probability of dying between any two ages for males and females.

## What it does
- Parses SSA life table HTML (ssa.gov/oact/STATS/table4c6.html) to extract year-by-year death probabilities for males and females
- Computes cumulative survival probabilities: P(die by age M | currently age N) for arbitrary age ranges
- Renders beautiful color-coded heatmaps with matplotlib: males in light blue, females in light pink, with probability values displayed as fractions (e.g., "1/82") or decimals
- Generates multiple charts covering different age ranges (e.g., 20-100, 1-116, 5-115) with configurable step sizes
- Output saved as high-DPI PNG images suitable for social media posts
- Existing readme.md contains a social media post in Russian discussing the findings (e.g., a 25-year-old man has a 1 in 82 chance of dying by age 30)
