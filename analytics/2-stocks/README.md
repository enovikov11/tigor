## What it does
A multi-faceted investment research project with several sub-studies:

### Options pricing research (`options/`, `v1-analyze.ipynb`, `v1-graphs.ipynb`, `v0-analyze.ipynb`)
- Black-Scholes and Black-76 option pricing models for SPX/XSP puts
- Backtesting put option "fairness" — comparing market prices against theoretical Black-Scholes prices using historical data from Polygon.io (2021-2025)
- Fair-price analysis for SPY, MSFT, and VOO options using implied volatility from market mid prices (Vanna-Volga)
- Hedge ratio calculations between VOO (S&P 500 ETF) and MSFT based on correlation and volatility
- Option chain visualization: strike vs price curves for multiple expiration dates
- Data pipeline: Polygon.io API for expired XSP put contracts, S3 flat files download, yfinance for XSP/IRX prices

### Non-ESG portfolio construction (`main.ipynb`)
- Constructs a $6,000 portfolio weighted across 7 non-ESG sectors: fast food, tobacco, alcohol, gambling, weed, HFT/exchanges, luxury goods
- Fetches market cap data from Polygon API, calculates industry weights as average of market-cap-weighted and equal-weighted allocations
- Computes weighted APY over 25 years (2000-2025)
- JavaScript scraper for Yahoo Finance API to get quarterly price history for all tickers

### Stock market timing (`stock-timing/`)
- Analyzes S&P 500 (VOO/GSPC) historical price data for optimal DCA entry timing
- Computes inflation-adjusted returns using US CPI data (1913-present, scraped from BLS)
- Rolling window analysis of N-year annualized returns (10yr, 20yr)
- Drop-diff scatter plots and expected value calculations for discount-based buying strategies

### Russian Central Bank rates (`cbr/`)
- Scrapes and analyzes cbr.ru key interest rate data from 2013-2025
- Computes daily compounding rates and cumulative growth factors

### Serbian government bonds / Belex (`belex/`)
- Scrapes belex.rs and javnidug.gov.rs for Serbian government security (RSRE) data
- Calculates price-based APY, coupon-based APY, and trade volume analysis
- Plots: coupon APY by maturity, RSRE trade APY scatter, short-term trade volume by month
- Compares against NBS (National Bank of Serbia) benchmark rates

### Legacy stock analysis (`v2.ipynb`, `v2.js`, `v0-*`)
- Earlier iterations of stock portfolio analysis and data downloading
- JavaScript scraper for non-ESG sector tickers via Yahoo Finance API
