Collection of algorithm implementations and math puzzles — primarily Fibonacci number calculations in multiple languages, string algorithms, and competitive programming solutions.

## What it does
- **Fibonacci implementations across 5 languages**: X86-64 NASM assembly, C (stack-based big integers), C++ (Boost multiprecision), Python, and Haskell — all computing arbitrary-precision Fibonacci numbers. Includes an amusing `fibo.md` documenting a buggy assembly version that printed garbage values.
- **String algorithms**: Substring search using character frequency counting (sliding window), and "one edit apart" check (insertion/deletion/substitution) via recursive backtracking
- **Competitive programming (SHAD)**: Five problems (A-E) covering: most frequent element, modular arithmetic with Fibonacci-like recurrence, Euler's totient function with prime factorization sieve, array sorting/summing, and grid/path traversal (partial)
- **Image puzzle generator**: Jupyter notebook that slices an image into a 16×16 grid of tiles and shuffles them (for creating jigsaw-like puzzles)
