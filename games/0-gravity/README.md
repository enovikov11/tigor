## What it does
An interactive N-body gravitational physics simulator. Place particles on a canvas and watch them orbit, collide, and form orbital patterns under customizable gravity laws. Features multiple versions with progressive improvements in physics accuracy, visual effects (tracers), wall behavior (bounce/dump), and configurable parameters via URL query params. Runs as a PWA with offline support.
