## What it does
An indie tic-tac-toe variant played on a 3D sphere surface. Built with Three.js for 3D rendering, jQuery UI for dialogs, and a custom raycaster-based click detection system. Players take turns placing marks on the faces of an icosahedral sphere, and the first to align three wins. Features a basic AI opponent using minimax-style win probability calculation.

## Key Files
- `index.html` - Main HTML entry point
- `model.js` - Game logic: turn management, win checking (predefined winning triplets), and state management
- `view.js` - 3D rendering with Three.js: icosahedron sphere, face coloring, OrbitControls camera
- `controller.js` - Input handling: raycaster-based face click detection with anti-drag filtering
- `ai.js` - AI opponent: win probability calculation with configurable max depth (minimax-style)
- `settings.js` - Configuration: winning triplets, language strings
- `style.css` - Styling
- `vendor/` - Three.js, jQuery, jQuery UI, OrbitControls (bundled)
