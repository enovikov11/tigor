## What it does
A multiplayer cursor position sharing demo over WebSockets. Each connected client gets a unique colored cursor dot, and their mouse position is broadcast in real-time to all other connected clients. Built as a proof-of-concept for real-time shared-state applications.

## Key Files
- `server.js` - Express + WS server: assigns each client a random color, broadcasts normalized cursor coordinates to all other connected clients, handles cleanup on disconnect
- `www/index.html` - Client-side: tracks mouse position and sends coordinates via WebSocket, renders other clients' colored cursor dots
- `package.json` - Node.js dependencies (express, ws)
