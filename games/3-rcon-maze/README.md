# RCON Maze Generator
> **Note:** This README was auto-generated by AI as a project summary. For detailed technical notes, see the project source.

## What it does
A procedural maze generator that outputs Minecraft `/setblock` commands via RCON protocol. Uses a randomized DFS (depth-first search) algorithm to carve passages through a grid of rooms, producing navigable maze structures in a Minecraft world. Includes both a linear command-output mode and a room-based visualization mode.

## Key Files
- `rooms/core.js` - Maze generation engine: DFS-based procedural generation with configurable room/border sizes, yields setBlock commands
- `rooms/view.js` - JavaScript visualization of the maze
- `rooms/view.html` - HTML page for visualizing generated mazes
- `rooms/apply.js` - Applies maze commands
- `linear/index.js` - Linear maze output mode
