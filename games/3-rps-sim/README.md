# games/3-rps-sim — Rock Paper Scissors Physics Simulator
> **Note:** This README was auto-generated by AI as a project summary. For detailed technical notes, see `README-tech.md`.

Browser-based particle physics simulation where 100 emoji characters (🪨📄✂️) bounce around the screen and eliminate each other based on Rock-Paper-Scissors rules until only one type survives.

## What it does

A single self-contained HTML file that runs a full physics simulation:

- **100 emoji particles** (🪨 rock, 📄 paper, ✂️ scissors) spawn at random positions with random velocities
- **Bouncing off walls**: particles bounce off screen edges with randomized rebound angles
- **Collision elimination**: when two particles come within 30px, the loser disappears (rock beats scissors, paper beats rock, scissors beats paper)
- **HUD counter**: live count of remaining 🪨📄✂️ in top-left corner
- **Winner detection**: when only one type remains, an overlay shows the winner with auto-replay countdown (5 seconds)
- **Controls**: pause/play button, Space key for pause, Escape to close overlay, replay/close buttons
- **Responsive**: handles window resize, visibility change (pauses when tab is hidden)

The simulation runs at 60fps using `requestAnimationFrame` with AABB collision detection (no physics engine — pure vanilla JS).
