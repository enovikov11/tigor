## What it does
A WebSockets-based online chess game with a FastAPI backend. Players connect via WebSocket using a hex-based game ID, and the server manages game sessions (board state, move history, turn tracking). Includes a static HTML frontend for the game board and a Jupyter notebook for experimentation. Supports up to two players (black/white) plus spectators.
