## What it does
Encodes an HTML payload (JavaScript) into a QR code image. When scanned by a phone camera, the QR code renders the embedded HTML — a fun demonstration of QR code capabilities beyond simple URLs. The example encodes `<script>alert(1)</script>` as a data URI.

- `encode.py` - Uses the `qrcode` library to generate a QR code containing a `data:text/html` URI with embedded JavaScript
- `snake.html` - HTML snake game (intended to be encoded into the QR code for a scannable mini-game)
- `qrcode.png` - Generated QR code image
