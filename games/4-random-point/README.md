## What it does
An animated visualization of random walk particles on an SVG canvas. Users can configure the number of points (up to 20,000), point radius, movement delta per step, and spawn rate via URL query parameters or form inputs. Shows real-time FPS and particle count stats. Includes a timing benchmark variant.
