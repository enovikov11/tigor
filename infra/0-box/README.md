## What it does

This is the central "home box" — an EPYC workstation running NixOS that hosts the local AI inference stack. It runs:

- **vLLM** serving Qwen3.6-27B-FP8 via Podman with NVIDIA GPU access (262K context, FP8 KV-cache, speculative decoding)
- **Open WebUI** chat interface as the front-end
- **Podman Compose** managed by systemd (`RemainAfterExit=true`) with rootless containers (gvisor runtime for non-GPU services)
- **ZFS** RAID-Z pools (SSD + HDD) with encrypted datasets
- **WireGuard** VPN connecting to the tgr.rs VPS
- **GPU power management**: locked at 450W, clocks pinned to 300-2400 MHz
- **UKI (Unified Kernel Image)** boot with netboot ramdisk

Additionally, the `flake.nix` defines a **Cloud Hypervisor VM** configuration with GPU passthrough, virtiofs, llama.cpp + OpenCode autonomous agent setup.

The `learnings/` directory contains extensive research notes on OS choices (why NixOS over Proxmox/ESXi/Alpine), container runtimes (Podman vs Docker vs k3s vs Kata containers), GPU passthrough, custom kernel building, Zigbee2MQTT, and security hardening. The `power/` directory has GPU stress-testing tools (CUDA kernels for memory/compute stress, DCGMI diagnostic runner, temperature margin monitoring).
