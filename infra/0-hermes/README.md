Automated script to provision a DigitalOcean Ubuntu droplet and install Hermes Agent with Telegram gateway.

## What it does

A single Python script (`deploy_hermes_droplet.py`) that:

1. **Creates a DigitalOcean droplet** (Ubuntu 26.04, 1 vCPU, 2GB RAM, ams3 region) with cloud-init
2. **Installs Hermes Agent** via the official installer (`--skip-setup --skip-browser --non-interactive`)
3. **Configures Hermes** with OpenRouter model + Telegram bot credentials (injected as base64-encoded env/config files)
4. **Sets up a systemd service** (`hermes-gateway`) to run the Telegram gateway as the `hermes` user with restart on failure
5. **Hardens the droplet**: unattended-upgrades, SSH key-only auth, proper file permissions
6. **Validates inputs** rigorously: checks DO account state, SSH key format, Telegram token format, no newlines in secrets

The script checks for existing droplets (refuses to create unless `ALLOW_EXISTING_DROPLETS=true`), reads SSH keys from the DO account, and waits up to 5 minutes for the droplet to become active.
