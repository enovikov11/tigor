Collection of standalone scripts and tools for infrastructure tasks: CI checks, data integrity, GitHub sync, Chia farming management, and file deduplication.

## What it does

A toolbox of independent utilities:

1. **CI/Quality checks**:
   - `check-python-ast.py` — Validates all .py files in a repo parse correctly via `ast.parse()` (skips __pycache__, node_modules, etc.)
   - `check-hashes.py` — Compares SHA256 hash files (backup vs production) to find missing/different files
   - `redeploy.sh` — Safe production redeploy: checks branch (main), verifies GPG-signed commit, runs CI checks, then `docker compose build && up`

2. **Data integrity**:
   - `hash-wip.py` — Walks a directory tree computing SHA256 hashes for all files (output: filepath, size, hash)
   - `rsync.sh` — Full-directory rsync with checksum mode and progress logging

3. **GitHub sync** (`local-gh-sync.py`):
   - Bi-directional rsync between monorepo and GitHub clones
   - `sync: in` — clones → monorepo (skips if monorepo has uncommitted changes)
   - `sync: out` — monorepo → clones (skips if either has changes)
   - Removes LFS pointer stubs, handles non-TTY output gracefully

4. **Chia farming management** (`chia-manage/`):
   - `manage.js` — Automated Chia plotter (k=32): spawns workers, distributes plots across output drives
   - `watch.js` — Monitoring: farming status, plot count, expected time to win, IO stats, memory — sends Telegram alerts every 4 hours (with Russian text: "УРА!!! НАМАЙНИЛ!!!")
   - `config.example.json` — Worker/temp/output drive configuration

5. **File Deduplicator** (`deduplicator/`):
   - C++17 project with Boost.Asio + SQLite + OpenSSL
   - `client` — filesystem indexer: traverses directories, computes SHA256, stores in SQLite
   - `server` — TCP server stub (Boost.Asio, partially implemented)
   - Uses level-by-level directory traversal (BFS-style) with Ctrl+C pause support
