## What it does
A Node.js tool for managing Chia cryptocurrency plot generation across multiple workers. Spawns parallel `chia plots create` processes (k32), distributes output across multiple storage paths based on capacity limits, and logs each worker's output to separate files. Designed to maximize plot production by keeping multiple workers busy across available storage.

- `manage.js` - Core logic: spawns chia plotter workers, manages output path distribution, tracks storage capacity, logs per-worker output
- `watch.js` - Monitoring/watch utility
- `package.json` - Node.js project configuration
- `config.example.json` - Configuration template: pool key, farmer key, worker definitions (temp paths), output paths with max count limits, log directory
