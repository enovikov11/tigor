## What it does
A C++ file deduplication tool with a client-server architecture. The client scans directories, computes file hashes (via OpenSSL), and stores results in an SQLite database to identify duplicate files. The server component provides a network listening interface (via Boost.Asio) for remote deduplication queries. Built with CMake, C++17, Boost, SQLite3, and OpenSSL.
