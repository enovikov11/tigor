# HackRF Spectrum Visualizer

> **Note:** This README was auto-generated by AI as a project summary. For detailed technical notes, see the project source.

## What it does

Real-time RF spectrum analyzer visualizer that pipes HackRF sweep data (10–5990 MHz range) into a live canvas heatmap. The Deno WebSocket server reads `hackrf_sweep` output and streams frequency power data to a browser client, which renders a grayscale heatmap of the RF spectrum with interactive frequency readout on hover.

## Key Files

- `aio.js` — All-in-one Deno server: runs `hackrf_sweep`, parses CSV output, serves HTML client, and streams data via WebSocket (run with `deno run --allow-all aio.js`)
- `view.py` — Offline post-processing script: reads `sweep.csv` and computes max signal strength per MHz, outputs `stat.json`
- `view.html` — Static HTML viewer for pre-captured spectrum data with pixel heatmap and mouse-hover frequency display
- `project.json` — Project metadata (stage: done)
