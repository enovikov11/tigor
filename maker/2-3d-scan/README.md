# 3D Scanner

> **Note:** This README was auto-generated by AI as a project summary. For detailed technical notes, see the project source.

## What it does

DIY turntable-based 3D scanner combining an ESP32-controlled stepper motor rotation platform with a Sony Alpha A6100 camera triggered via gphoto2. The system captures sequential images as an object rotates (28BYJ-48 stepper, 2048 steps per full circle), producing image sequences for photogrammetric 3D reconstruction.

## Key Files

- `sketch.ino` — ESP32 firmware controlling the 28BYJ-48 stepper motor via direct GPIO register manipulation; accepts step commands over serial (positive = forward, negative = reverse)
- `run.py` — Python automation script: connects to ESP32 via serial, triggers camera capture via gphoto2, then sends rotation step command in a loop
- `models/table.scad` — OpenSCAD model for the 3D-printed turntable base with shaft adapter and mounting platform
- `models/table.stl` — Pre-exported STL for 3D printing the rotation platform
- `index.html` — Dark-themed HTML page for viewing the output scan video
- `CLAUDE.md` — Project description with hardware list
- `project.json` — Project metadata (stage: pilot)
