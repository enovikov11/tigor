## What it does

Bluetooth UART bridge project enabling bidirectional serial communication between an Arduino and mobile/PC clients. The Arduino sketch bridges Serial (USB) and Serial1 (Bluetooth module). Includes an Android app (Kotlin) that connects to a specific Bluetooth MAC address and sends data, plus a Java desktop utility for UUID generation.

## Key Files

- `sketch.ino` — Arduino sketch that bridges USB Serial and Serial1 (Bluetooth): toggles pin 13 as enable, then forwards bytes bidirectionally between the two serial ports
