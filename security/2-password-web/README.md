## What it does

Browser-based deterministic password generator using SHA-3-256. Takes a master seed (entered securely with masked input) and generates site-specific passwords by hashing `seed + target + login + year`. Supports multiple output encodings (15-digit PIN + suffix, 20-char hex, 4/8-digit PINs). Account list persists in localStorage. Edit mode allows managing the account database inline.
