## What it does
Production Telegram inline bot that serves user-owned NFT collections (манулы/Pallas cats, гуси/geese, граффити/graffiti) via inline queries. When a user invokes the bot inline (e.g. `@pet101bot`), it returns their collection as inline photo results. Connects to a MariaDB pool for persistent NFT storage and verifies the complete dataset integrity via SHA-256 hash on startup.
