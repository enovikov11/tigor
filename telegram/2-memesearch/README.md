# MemeSearch
> **Note:** This README was auto-generated by AI as a project summary. For detailed technical notes, see the project source.

## What it does
Semantic meme search — sends a text query and gets back the top 10 visually similar memes. Uses OpenAI's text-embedding-3-large model for text-to-embedding and FAISS (L2 distance) for fast vector search over a pre-built index of meme embeddings stored as a memory-mapped binary file. Tracks performance metrics (embedding, calculation, send latency) per query.

## Key Files
- `main.ipynb` - Jupyter notebook for building the FAISS index: exports memes from MariaDB, generates OpenAI descriptions/embeddings, writes binary index file
- `memesearch/main.py` - Telegram bot that loads the mmap'd index and performs cosine similarity search on incoming text queries
- `memesearch/Dockerfile` - Production container serving the bot with pre-loaded meme database
- `project.json` - Stage: pilot, use: maybe
