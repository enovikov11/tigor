## What it does
Telegram bot that generates HMAC-SHA256 signed bearer tokens for the Tigor service. Users message the bot and receive a token containing their Telegram user ID, priority, daily message limit, token limit per message, and expiration date — all cryptographically signed to prevent tampering. Tokens use a pipe-delimited format with a URL-safe base64 signature.
