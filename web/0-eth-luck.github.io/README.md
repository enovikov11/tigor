## What it does
"Гадание на эфириумной гуще" — fortune telling using Ethereum block hashes. Users type yes/no questions into a form, the app fetches the latest block hash from Ethereum mainnet via ethers.js, converts the hash to binary, and uses each bit as a yes/no answer for each question. Beautiful black-and-red themed single-page app.
