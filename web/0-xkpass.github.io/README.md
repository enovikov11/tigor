## What it does
In-browser XKCD-style password generator based on the famous XKCD #936 comic. Generates 4-word passwords with 48 bits of entropy using the EFF large wordlist (7,776 words, indexed to 4096 for 12 bits/word). Uses `crypto.getRandomValues()` for cryptographically secure randomness and Subresource Integrity (SRI) to verify the wordlist hasn't been tampered with. Available in English and Russian.
