# Sync Player
> **Note:** This README was auto-generated by AI as a project summary. For detailed technical notes, see the project source.

## What it does
Multi-client synchronized video player. Uses FastAPI + WebSockets to coordinate video playback across multiple viewers in real-time. Each client reports when it's ready ("canPlay"), the server broadcasts play commands with a 2-second lookahead, and clients apply a user-configurable latency correction offset. Includes a binary clock display and video selection via radio buttons.

## Key Files
- `main.py` - FastAPI server: WebSocket hub for broadcast/sync, static file serving for videos and HTML, session management
