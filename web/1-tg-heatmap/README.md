## What it does
Visualizes Telegram chat export data as a monthly bar chart heatmap. Users upload a Telegram JSON export, and the app renders daily message counts grouped by month — with rainbow coloring by day of week (Mon=red through Sun=violet). Includes range filtering via dropdowns to zoom into specific periods. Pure client-side, zero dependencies.

## Key Files
- `telegram-heatmap.html` - Single-file app: HTML file picker, JavaScript parsing of Telegram export JSON, dynamic bar chart rendering with CSS-styled bars
