## What it does
"ШРИ CI" — a distributed continuous integration system with a server-agent architecture. The server (Express.js + SQLite) provides a React UI for submitting builds (repo, commit hash, build command) and viewing build results. Build agents connect to the server, receive tasks, check out commits, run build commands, and report stdout/stderr/status back. Uses cookie-based secret authentication.
